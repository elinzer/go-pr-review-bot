# PR Review Bot — Go Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the Python `pr-review-bot` to Go as a single static binary, preserving behavior and the `state.json` format, while adopting `context.Context` timeouts, a typed state file, and `claude-opus-5`.

**Architecture:** A `cmd/pr-review-bot` entrypoint wires eight `internal/` packages in the same dependency order as the Python modules. Each package is ported test-first: translate the Python test to Go, watch it fail, then implement. The Python repo at `../pr-review-bot` stays running and untouched as the behavioral reference.

**Tech Stack:** Go 1.26, `github.com/anthropics/anthropic-sdk-go`, `github.com/joho/godotenv`, and the standard library (`net/http`, `encoding/json`, `regexp`, `log/slog`, `testing`, `net/http/httptest`).

## Global Constraints

- **Go version:** 1.26 (installed: go1.26.3 darwin/arm64). `go.mod` declares `go 1.26`.
- **Module path:** `github.com/elinzer/go-pr-review-bot` — replace `elinzer` with your GitHub username. Nothing depends on this resolving unless you publish it.
- **External dependencies: exactly two.** `github.com/anthropics/anthropic-sdk-go` and `github.com/joho/godotenv`. Everything else is stdlib. Do not add `go-github`, a testing framework, an assertion library, or a logging library.
- **No GitHub SDK.** All four GitHub endpoints are hand-rolled with `net/http` + `encoding/json`.
- **`state.json` format is frozen.** The Go binary must read and write the exact JSON shape the Python version produces, so you can point both at the same file and diff. Existing file: `../pr-review-bot/state.json`.
- **Model default:** `claude-opus-5` (not `claude-opus-4-7`).
- **`max_tokens`: 16000**, not 8192. Thinking is on by default on `claude-opus-5` and `max_tokens` caps thinking + response text together.
- **Every outbound call takes a `context.Context`** as its first parameter. No package-level HTTP clients without timeouts.
- **Comment cap stays at 5** per PR. Severities stay `bug` and `question` only.
- **No comments in code** unless the behavior is dangerous and non-obvious.
- **Commit after every task.** Conventional commit prefixes (`feat:`, `test:`, `chore:`).

### Task 1: Scaffold the repo and port `models.py`

> **Go concept: packages are directories, and `internal/` is enforced by the compiler.** Any package under a directory named `internal/` can only be imported by code rooted at `internal/`'s parent. It is not a naming convention — the toolchain rejects the import. This gives you Python's `_private` prefix, but actually enforced.
>
> **Go concept: there is no `set` type.** Python's `{f.path for f in self.files}` has no direct equivalent. The idiom is `map[string]struct{}` — a map whose values carry zero bytes. You test membership with the two-value form `_, ok := m[key]`. `struct{}{}` looks strange; it's an empty struct literal, and it is genuinely free at runtime.

### Task 2: Port `config.py`

> **Go concept: multiple return values replace exceptions.** `load_config()` raises `RuntimeError` on bad input. Go functions return `(Config, error)` and the caller must handle both. There is no `try`. The convention is `if err != nil { return ... }` immediately after every fallible call — this is the shape you will write hundreds of times.
>
> **Go concept: `errors.New` vs `fmt.Errorf`.** Use `errors.New` for a fixed message, `fmt.Errorf` when you need to interpolate. `fmt.Errorf` with the `%w` verb *wraps* an error so callers can unwrap it later with `errors.Is`; here you have no wrapping to do, so plain `%s`/`%q` verbs are correct.
>
> **Improvement over Python:** this adds `HTTPTimeout` and `AnthropicTimeout` to `Config`. The Python code hardcoded `timeout=10` in `jira_client.py:47` and `timeout=5` in `notifier.py:37`, with no timeout at all on the Anthropic call.

```go
package config

import (
	"fmt"
	"os"
	"strconv"
	"strings"
	"time"

	"github.com/joho/godotenv"
)

type Config struct {
	GitHubPAT       string
	AnthropicAPIKey string
	JiraEmail       string
	JiraAPIToken    string
	JiraBaseURL     string
	GitHubTeamSlug  string

	PollIntervalSeconds int
	PRMaxAgeDays        int

	Model     string
	StatePath string
	DryRun    bool
	LogLevel  string

	SlackWebhookURL string

	HTTPTimeout      time.Duration
	AnthropicTimeout time.Duration
}

var required = []string{
	"GITHUB_PAT",
	"ANTHROPIC_API_KEY",
	"JIRA_EMAIL",
	"JIRA_API_TOKEN",
	"JIRA_BASE_URL",
	"GITHUB_TEAM_SLUG",
}

func Load(loadDotenv bool) (Config, error) {
	if loadDotenv {
		_ = godotenv.Load()
	}

	var missing []string
	for _, key := range required {
		if os.Getenv(key) == "" {
			missing = append(missing, key)
		}
	}
	if len(missing) > 0 {
		return Config{}, fmt.Errorf("missing required env vars: %s", strings.Join(missing, ", "))
	}

	pollInterval, err := envInt("POLL_INTERVAL_SECONDS", 600)
	if err != nil {
		return Config{}, err
	}
	maxAge, err := envInt("PR_MAX_AGE_DAYS", 14)
	if err != nil {
		return Config{}, err
	}

	return Config{
		GitHubPAT:       os.Getenv("GITHUB_PAT"),
		AnthropicAPIKey: os.Getenv("ANTHROPIC_API_KEY"),
		JiraEmail:       os.Getenv("JIRA_EMAIL"),
		JiraAPIToken:    os.Getenv("JIRA_API_TOKEN"),
		JiraBaseURL:     strings.TrimRight(os.Getenv("JIRA_BASE_URL"), "/"),
		GitHubTeamSlug:  os.Getenv("GITHUB_TEAM_SLUG"),

		PollIntervalSeconds: pollInterval,
		PRMaxAgeDays:        maxAge,

		Model:     envString("MODEL", "claude-opus-5"),
		StatePath: envString("STATE_PATH", "./state.json"),
		DryRun:    envBool("DRY_RUN"),
		LogLevel:  envString("LOG_LEVEL", "INFO"),

		SlackWebhookURL: os.Getenv("SLACK_WEBHOOK_URL"),

		HTTPTimeout:      10 * time.Second,
		AnthropicTimeout: 5 * time.Minute,
	}, nil
}

func envString(key, fallback string) string {
	if v := os.Getenv(key); v != "" {
		return v
	}
	return fallback
}

func envInt(key string, fallback int) (int, error) {
	raw := os.Getenv(key)
	if raw == "" {
		return fallback, nil
	}
	n, err := strconv.Atoi(raw)
	if err != nil {
		return 0, fmt.Errorf("%s must be an integer, got %q", key, raw)
	}
	return n, nil
}

func envBool(key string) bool {
	switch strings.ToLower(strings.TrimSpace(os.Getenv(key))) {
	case "true", "1", "yes", "on":
		return true
	default:
		return false
	}
}
```

### Task 3: Port `state.py` with a typed state file

> **Go concept: pointers signal absence.** Python's `is_reviewed` checks `"review_id" in entry` — key *presence*. A Go struct field always exists, so presence has to be encoded another way. For `ReviewID` the value `0` is a legal review ID, so you cannot use the zero value as "absent" — the field is `*int64`, where `nil` means never set. For `DryRunLoggedAt` the empty string is not a legal timestamp, so a plain `string` is fine. Choosing between these two per field is the actual skill; there is no universal answer.
>
> **Go concept: `omitempty` keeps the file identical to Python's.** Python only writes keys it has set. Without `omitempty`, Go would emit `"review_id": null, "skipped_manual": false` for every entry and the file would stop matching. `omitempty` omits zero values — and for a pointer field, `nil` is the zero value.
>
> **Go concept: inject the clock.** Python calls `datetime.now(timezone.utc)` inline, which is untestable without monkeypatching. The Go idiom is a `now func() time.Time` field on the struct, defaulting to `time.Now` and overridden in tests. Same trick as dependency injection, applied to time.
>
> **One cosmetic difference is expected.** Python's `.isoformat()` writes `2026-06-19T17:37:00.123456+00:00`; Go's `time.RFC3339` writes `2026-06-19T17:37:00Z`. Both are valid ISO 8601, nothing reads these timestamps back, and the *keys* are identical — which is what "frozen format" means here. Do not chase byte-for-byte equality on the values.

```go
package state

import (
	"encoding/json"
	"os"
	"path/filepath"
	"time"

	"github.com/elinzer/go-pr-review-bot/internal/models"
)

type entry struct {
	ReviewID         *int64 `json:"review_id,omitempty"`
	ReviewedAt       string `json:"reviewed_at,omitempty"`
	ParseFailedCount int    `json:"parse_failed_count,omitempty"`
	DryRunLoggedAt   string `json:"dry_run_logged_at,omitempty"`
	SkippedManual    bool   `json:"skipped_manual,omitempty"`
}

type fileData struct {
	Reviews map[string]*entry `json:"reviews"`
}

type State struct {
	path string
	data fileData
	Now  func() time.Time
}

func Load(path string) (*State, error) {
	s := &State{
		path: path,
		data: fileData{Reviews: map[string]*entry{}},
		Now:  time.Now,
	}

	raw, err := os.ReadFile(path)
	if err != nil {
		return s, nil
	}
	var parsed fileData
	if err := json.Unmarshal(raw, &parsed); err != nil {
		return s, nil
	}
	if parsed.Reviews != nil {
		s.data.Reviews = parsed.Reviews
	}
	return s, nil
}

func (s *State) entryFor(url string) *entry {
	e, ok := s.data.Reviews[url]
	if !ok {
		e = &entry{}
		s.data.Reviews[url] = e
	}
	return e
}

func (s *State) IsReviewed(url string) bool {
	e, ok := s.data.Reviews[url]
	if !ok {
		return false
	}
	return e.ReviewID != nil || e.DryRunLoggedAt != ""
}

func (s *State) IsSkipped(url string) bool {
	e, ok := s.data.Reviews[url]
	return ok && e.SkippedManual
}

func (s *State) MarkReviewed(url string, reviewID int64) error {
	e := s.entryFor(url)
	e.ReviewID = &reviewID
	e.ReviewedAt = s.timestamp()
	return s.save()
}

func (s *State) MarkDryRunReviewed(url string) error {
	e := s.entryFor(url)
	e.DryRunLoggedAt = s.timestamp()
	return s.save()
}

func (s *State) MarkSkippedManual(url string) error {
	s.entryFor(url).SkippedManual = true
	return s.save()
}

func (s *State) IncrementParseFailed(url string) (int, error) {
	e := s.entryFor(url)
	e.ParseFailedCount++
	if err := s.save(); err != nil {
		return e.ParseFailedCount, err
	}
	return e.ParseFailedCount, nil
}

func (s *State) Unreviewed(prs []models.PullRequestSummary) []models.PullRequestSummary {
	var out []models.PullRequestSummary
	for _, pr := range prs {
		if !s.IsReviewed(pr.URL) && !s.IsSkipped(pr.URL) {
			out = append(out, pr)
		}
	}
	return out
}

func (s *State) timestamp() string {
	return s.Now().UTC().Format(time.RFC3339)
}

func (s *State) save() error {
	if dir := filepath.Dir(s.path); dir != "" && dir != "." {
		if err := os.MkdirAll(dir, 0o755); err != nil {
			return err
		}
	}

	raw, err := json.MarshalIndent(s.data, "", "  ")
	if err != nil {
		return err
	}

	tmp := s.path + ".tmp"
	if err := os.WriteFile(tmp, raw, 0o600); err != nil {
		return err
	}
	return os.Rename(tmp, s.path)
}
```

### Task 4: Port `prompt.py` using embedded files

> **Go concept: raw string literals cannot contain backticks.** `` `...` `` is Go's triple-quote equivalent, but there is no escape for a backtick inside one — and your review system prompt contains ```` ```json ```` fences. You could concatenate around them, but the idiomatic answer for a large text blob is `//go:embed`: put the prompt in a real `.md` file and have the compiler bake its bytes into the binary at build time. The file ships inside the binary; there is nothing to install alongside it.
>
> **Go concept: `//go:embed` is a directive, not a comment.** It must sit immediately above the `var` it fills, with no blank line, and the file must be in the same directory or below. The `_ "embed"` import is required even though you never reference the package by name — the underscore says "import for side effects only."
>
> **Go concept: build strings with `strings.Builder`, not `+=` in a loop.** Go strings are immutable, so `s += x` in a loop allocates a new string every iteration. `strings.Builder` amortizes it.

```go
package prompt

import (
	_ "embed"
	"encoding/json"
	"fmt"
	"strings"

	"github.com/elinzer/go-pr-review-bot/internal/models"
)

//go:embed review_system.md
var ReviewSystem string

//go:embed critique_system.md
var CritiqueSystem string

type Messages struct {
	System string
	User   string
}

func BuildReview(pr models.PRContext, jira *models.JiraContext) Messages {
	var b strings.Builder

	fmt.Fprintf(&b, "# Pull request\n\n")
	fmt.Fprintf(&b, "Repo: %s\n", pr.Summary.RepoFullName)
	fmt.Fprintf(&b, "Title: %s\n", pr.Summary.Title)
	fmt.Fprintf(&b, "Branch: %s\n\n", pr.Summary.Branch)

	body := pr.Summary.Body
	if body == "" {
		body = "(empty)"
	}
	fmt.Fprintf(&b, "## PR body\n%s\n\n", body)

	if jira != nil {
		fmt.Fprintf(&b, "## Jira context\n%s\n\n", formatJira(*jira))
	}

	fmt.Fprintf(&b, "## Diff\n%s\n", formatFiles(pr))

	return Messages{System: ReviewSystem, User: b.String()}
}

func BuildCritique(pr models.PRContext, review models.Review) (Messages, error) {
	comments := review.Comments
	if comments == nil {
		comments = []models.Comment{}
	}
	payload := models.Review{Summary: review.Summary, Comments: comments}

	encoded, err := json.MarshalIndent(payload, "", "  ")
	if err != nil {
		return Messages{}, fmt.Errorf("encoding draft review: %w", err)
	}

	user := fmt.Sprintf(
		"## Diff\n%s\n\n## Draft review\n```json\n%s\n```",
		formatFiles(pr),
		encoded,
	)

	return Messages{System: CritiqueSystem, User: user}, nil
}

func formatFiles(pr models.PRContext) string {
	parts := make([]string, 0, len(pr.Files))
	for _, f := range pr.Files {
		parts = append(parts, fmt.Sprintf(
			"=== FILE: %s (+%d -%d) ===\n%s\n",
			f.Path, f.Additions, f.Deletions, f.Patch,
		))
	}
	return strings.Join(parts, "\n")
}

func formatJira(j models.JiraContext) string {
	return fmt.Sprintf(
		"Jira ticket: %s\nTitle: %s\nDescription:\n%s\n\nAcceptance criteria:\n%s",
		j.Key, j.Title, j.Description, j.AcceptanceCriteria,
	)
}
```

### Task 5: Port the reviewer's diff validation

> **Go concept: unexported identifiers start with a lowercase letter.** Python's `_new_line_ranges` is private by convention only. In Go, `newLineRanges` is genuinely invisible outside package `reviewer` — the compiler enforces it. `Validate` is capitalized because `poller` needs it. This is the whole visibility system: one bit, encoded in the first character.
>
> **Go concept: `regexp` is RE2, not PCRE.** No backreferences, no lookahead. Every pattern in this file is fine, but if you ever reach for `(?=...)` the compiler will reject it at `MustCompile` time — which panics at package init, so you find out immediately rather than at request time.
>
> **Go concept: `MustCompile` at package scope.** Compiling a regex is expensive; doing it inside a function that runs per-comment wastes work. The idiom is a package-level `var x = regexp.MustCompile(...)`. `Must` prefixes in Go mean "panic instead of returning an error" and are only acceptable for values that are constant at compile time — a hardcoded regex qualifies.

```go
package reviewer

import (
	"regexp"
	"strconv"
	"strings"

	"github.com/elinzer/go-pr-review-bot/internal/models"
)

const MaxComments = 5

var hunkHeaderRe = regexp.MustCompile(`^@@ -\d+(?:,\d+)? \+(\d+)(?:,(\d+))? @@`)

type lineRange struct {
	lo int
	hi int
}

func newLineRanges(patch string) []lineRange {
	var ranges []lineRange
	for _, line := range strings.Split(patch, "\n") {
		m := hunkHeaderRe.FindStringSubmatch(line)
		if m == nil {
			continue
		}
		start, err := strconv.Atoi(m[1])
		if err != nil {
			continue
		}
		count := 1
		if m[2] != "" {
			parsed, err := strconv.Atoi(m[2])
			if err != nil {
				continue
			}
			count = parsed
		}
		ranges = append(ranges, lineRange{lo: start, hi: start + count - 1})
	}
	return ranges
}

func lineInHunks(line int, patch string) bool {
	for _, r := range newLineRanges(patch) {
		if line >= r.lo && line <= r.hi {
			return true
		}
	}
	return false
}

func newFileText(patch string) string {
	var kept []string
	for _, line := range strings.Split(patch, "\n") {
		line = strings.TrimSuffix(line, "\r")
		if strings.HasPrefix(line, "+++") || strings.HasPrefix(line, "---") {
			continue
		}
		if strings.HasPrefix(line, "+") || strings.HasPrefix(line, " ") {
			kept = append(kept, line[1:])
		}
	}
	return strings.Join(kept, "\n")
}

func quoteInPatch(quote, patch string) bool {
	if quote == "" {
		return false
	}
	return strings.Contains(newFileText(patch), quote)
}

func Validate(review models.Review, pr models.PRContext) models.Review {
	patches := make(map[string]string, len(pr.Files))
	for _, f := range pr.Files {
		patches[f.Path] = f.Patch
	}

	var kept []models.Comment
	for _, c := range review.Comments {
		patch, ok := patches[c.File]
		if !ok {
			continue
		}
		if !lineInHunks(c.Line, patch) {
			continue
		}
		if !quoteInPatch(c.Evidence.QuotedCode, patch) {
			continue
		}
		kept = append(kept, c)
		if len(kept) >= MaxComments {
			break
		}
	}

	return models.Review{Summary: review.Summary, Comments: kept}
}
```

### Task 6: Port the reviewer's tolerant JSON parsing

> **Go concept: `json.RawMessage` defers a decision.** The model sometimes returns `"line": 42` and sometimes `"line": "40-44"`. Python's `_parse_line` handles this with `isinstance`. In Go, declaring the field as `json.RawMessage` tells `encoding/json` "hand me the raw bytes, I'll decode this myself" — then you try `int` first and fall back to `string`. This is the standard escape hatch for a field whose type varies.
>
> **Go concept: a nil slice and an empty slice are both `len() == 0`.** `var c []models.Comment` is nil; `[]models.Comment{}` is empty. They behave identically for `len`, `range`, and `append` — but marshal differently: nil becomes `null`, empty becomes `[]`. That matters in Task 4's critique payload, which is why `BuildCritique` normalizes it.
>
> **Go concept: sentinel errors.** `ErrUnparseable` is a package-level `error` value that callers compare with `errors.Is`. The poller needs to distinguish "the model returned garbage" (increment the failure counter) from "the network died" (just log it) — exactly the branch at `poller.py:47`. A string match on the message would work until someone rewords it; a sentinel will not silently break.

```go
package reviewer

import (
	"encoding/json"
	"errors"
	"fmt"
	"regexp"
	"strconv"
	"strings"

	"github.com/elinzer/go-pr-review-bot/internal/models"
)

var ErrUnparseable = errors.New("model response was not parseable JSON")

var jsonFenceRe = regexp.MustCompile("(?s)```(?:json)?\\s*(\\{.*?\\})\\s*```")

func extractJSON(text string) string {
	if matches := jsonFenceRe.FindAllStringSubmatch(text, -1); len(matches) > 0 {
		return matches[len(matches)-1][1]
	}
	first := strings.Index(text, "{")
	last := strings.LastIndex(text, "}")
	if first != -1 && last > first {
		return text[first : last+1]
	}
	return text
}

func parseLine(raw json.RawMessage) (int, error) {
	if len(raw) == 0 {
		return 0, fmt.Errorf("line field is absent")
	}

	var n int
	if err := json.Unmarshal(raw, &n); err == nil {
		return n, nil
	}

	var s string
	if err := json.Unmarshal(raw, &s); err != nil {
		return 0, fmt.Errorf("line field %s is neither a number nor a string", raw)
	}

	head, _, _ := strings.Cut(s, "-")
	n, err := strconv.Atoi(strings.TrimSpace(head))
	if err != nil {
		return 0, fmt.Errorf("line field %q does not start with a number", s)
	}
	return n, nil
}

type rawComment struct {
	File     string           `json:"file"`
	Line     json.RawMessage  `json:"line"`
	Severity string           `json:"severity"`
	Body     string           `json:"body"`
	Evidence *models.Evidence `json:"evidence"`
}

type rawReview struct {
	Summary  string       `json:"summary"`
	Comments []rawComment `json:"comments"`
}

func parseComment(rc rawComment) (models.Comment, bool) {
	severity := models.Severity(rc.Severity)
	if !severity.Valid() {
		return models.Comment{}, false
	}
	if rc.File == "" || rc.Body == "" {
		return models.Comment{}, false
	}

	line, err := parseLine(rc.Line)
	if err != nil {
		return models.Comment{}, false
	}

	var evidence models.Evidence
	if rc.Evidence != nil {
		evidence = *rc.Evidence
	}

	return models.Comment{
		File:     rc.File,
		Line:     line,
		Severity: severity,
		Body:     rc.Body,
		Evidence: evidence,
	}, true
}

func ParseReviewJSON(raw string) (models.Review, error) {
	var parsed rawReview
	if err := json.Unmarshal([]byte(extractJSON(raw)), &parsed); err != nil {
		return models.Review{}, fmt.Errorf("%w: %v", ErrUnparseable, err)
	}

	var comments []models.Comment
	for _, rc := range parsed.Comments {
		if c, ok := parseComment(rc); ok {
			comments = append(comments, c)
		}
	}

	return models.Review{Summary: parsed.Summary, Comments: comments}, nil
}
```

```go
	"context"
	"encoding/json"
	"fmt"

	"github.com/elinzer/go-pr-review-bot/internal/models"
	"github.com/elinzer/go-pr-review-bot/internal/prompt"
)

type MessageCreator interface {
	CreateMessage(ctx context.Context, system, user string) (string, error)
}

type Reviewer struct {
	Client MessageCreator
}

func (r Reviewer) Review(ctx context.Context, pr models.PRContext, jira *models.JiraContext) (models.Review, error) {
	msgs := prompt.BuildReview(pr, jira)

	raw, err := r.Client.CreateMessage(ctx, msgs.System, msgs.User)
	if err != nil {
		return models.Review{}, fmt.Errorf("review pass: %w", err)
	}

	return ParseReviewJSON(raw)
}

type critiqueVerdict struct {
	Keep []int `json:"keep"`
}

func (r Reviewer) SelfCritique(ctx context.Context, review models.Review, pr models.PRContext) (models.Review, error) {
	if len(review.Comments) == 0 {
		return review, nil
	}

	msgs, err := prompt.BuildCritique(pr, review)
	if err != nil {
		return models.Review{}, err
	}

	raw, err := r.Client.CreateMessage(ctx, msgs.System, msgs.User)
	if err != nil {
		return models.Review{}, fmt.Errorf("critique pass: %w", err)
	}

	var verdict critiqueVerdict
	if err := json.Unmarshal([]byte(extractJSON(raw)), &verdict); err != nil {
		return models.Review{Summary: review.Summary}, nil
	}

	keep := make(map[int]struct{}, len(verdict.Keep))
	for _, i := range verdict.Keep {
		keep[i] = struct{}{}
	}

	var kept []models.Comment
	for i, c := range review.Comments {
		if _, ok := keep[i]; ok {
			kept = append(kept, c)
		}
	}

	return models.Review{Summary: review.Summary, Comments: kept}, nil
}

func (r Reviewer) ReviewPR(ctx context.Context, pr models.PRContext, jira *models.JiraContext) (models.Review, error) {
	draft, err := r.Review(ctx, pr, jira)
	if err != nil {
		return models.Review{}, err
	}

	critiqued, err := r.SelfCritique(ctx, draft, pr)
	if err != nil {
		return models.Review{}, err
	}

	return Validate(critiqued, pr), nil
}
```

> **Go concept: an adapter isolates a dependency you do not control.** `reviewer` never imports the Anthropic SDK — it only knows `MessageCreator`. package anthropicclient

```go
import (
	"context"
	"errors"
	"fmt"
	"time"

	"github.com/anthropics/anthropic-sdk-go"
	"github.com/anthropics/anthropic-sdk-go/option"
)

const maxTokens = 16000

type Client struct {
	api   anthropic.Client
	model anthropic.Model
}

func New(apiKey, model string, timeout time.Duration) *Client {
	return &Client{
		api: anthropic.NewClient(
			option.WithAPIKey(apiKey),
			option.WithRequestTimeout(timeout),
		),
		model: anthropic.Model(model),
	}
}

func (c *Client) CreateMessage(ctx context.Context, system, user string) (string, error) {
	msg, err := c.api.Messages.New(ctx, anthropic.MessageNewParams{
		Model:     c.model,
		MaxTokens: maxTokens,
		System:    []anthropic.TextBlockParam{{Text: system}},
		Messages: []anthropic.MessageParam{
			anthropic.NewUserMessage(anthropic.NewTextBlock(user)),
		},
	})
	if err != nil {
		var apiErr *anthropic.Error
		if errors.As(err, &apiErr) {
			return "", fmt.Errorf("anthropic api error (status %d, request %s): %w",
				apiErr.StatusCode, apiErr.RequestID, err)
		}
		return "", fmt.Errorf("anthropic request failed: %w", err)
	}

	for _, block := range msg.Content {
		if block.Type == "text" && block.Text != "" {
			return block.Text, nil
		}
	}

	return "", fmt.Errorf("anthropic returned no text content (stop reason %q)", msg.StopReason)
}
```

### Task 9: Build the GitHub transport and the search query

> **Go concept: you decode JSON into structs you declare.** There is no `response.json()` returning a dict. You write a struct describing the shape you care about, tag its fields, and `json.Decode` fills it — every other field in the payload is silently ignored. This is why hand-rolling four endpoints is reasonable: you only describe the ~10 fields you actually use.
>
> **Go concept: `defer resp.Body.Close()` immediately after checking the error.** An unclosed response body leaks a connection. `defer` runs when the surrounding function returns, so the idiom is to write it on the line right after `if err != nil`. Forgetting it is the single most common Go HTTP bug.
>
> **Simplification over Python:** PyGithub's `create_review(commit=repo.get_commit(sha), ...)` made an extra API call just to turn a SHA into a commit object. The REST API takes `commit_id` as a plain string, so that request disappears.

```go
package ghclient

import (
	"bytes"
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"net/http"
	"strings"
	"time"
)

const defaultBaseURL = "https://api.github.com"

type Client struct {
	BaseURL    string
	RetryDelay time.Duration
	Now        func() time.Time

	pat        string
	teamSlug   string
	maxAgeDays int
	http       *http.Client
}

func New(pat, teamSlug string, maxAgeDays int, timeout time.Duration) *Client {
	return &Client{
		BaseURL:    defaultBaseURL,
		RetryDelay: 5 * time.Second,
		Now:        time.Now,
		pat:        pat,
		teamSlug:   teamSlug,
		maxAgeDays: maxAgeDays,
		http:       &http.Client{Timeout: timeout},
	}
}

func (c *Client) do(ctx context.Context, method, path string, body any, out any) error {
	var reader io.Reader
	if body != nil {
		encoded, err := json.Marshal(body)
		if err != nil {
			return fmt.Errorf("encoding request body: %w", err)
		}
		reader = bytes.NewReader(encoded)
	}

	req, err := http.NewRequestWithContext(ctx, method, c.BaseURL+path, reader)
	if err != nil {
		return fmt.Errorf("building request: %w", err)
	}
	req.Header.Set("Authorization", "Bearer "+c.pat)
	req.Header.Set("Accept", "application/vnd.github+json")
	req.Header.Set("X-GitHub-Api-Version", "2022-11-28")
	if body != nil {
		req.Header.Set("Content-Type", "application/json")
	}

	resp, err := c.http.Do(req)
	if err != nil {
		return fmt.Errorf("%s %s: %w", method, path, err)
	}
	defer resp.Body.Close()

	if resp.StatusCode < 200 || resp.StatusCode > 299 {
		snippet, _ := io.ReadAll(io.LimitReader(resp.Body, 512))
		return &APIError{
			Method:     method,
			Path:       path,
			StatusCode: resp.StatusCode,
			Body:       strings.TrimSpace(string(snippet)),
		}
	}

	if out == nil {
		return nil
	}
	if err := json.NewDecoder(resp.Body).Decode(out); err != nil {
		return fmt.Errorf("decoding %s %s response: %w", method, path, err)
	}
	return nil
}

type APIError struct {
	Method     string
	Path       string
	StatusCode int
	Body       string
}

func (e *APIError) Error() string {
	return fmt.Sprintf("github %s %s: status %d: %s", e.Method, e.Path, e.StatusCode, e.Body)
}

func (e *APIError) Retryable() bool {
	return e.StatusCode == http.StatusNotFound || e.StatusCode >= 500
}

func (c *Client) doWithRetry(ctx context.Context, method, path string, body any, out any) error {
	err := c.do(ctx, method, path, body, out)
	if err == nil {
		return nil
	}

	var apiErr *APIError
	if !errors.As(err, &apiErr) || !apiErr.Retryable() {
		return err
	}

	select {
	case <-ctx.Done():
		return ctx.Err()
	case <-time.After(c.RetryDelay):
	}

	return c.do(ctx, method, path, body, out)
}
```

Two things to notice in this file. `APIError` is a custom error type: any type with an `Error() string` method satisfies the built-in `error` interface, and `errors.As` walks the `%w` wrapping chain to find one of a specific type — that is how `doWithRetry` decides whether a failure is worth retrying without string-matching the message. And the retry `select` blocks on either the timer or context cancellation, so a shutdown mid-backoff returns immediately instead of sleeping out the full delay.

```go
func (c *Client) searchQuery() string {
	cutoff := c.Now().UTC().AddDate(0, 0, -c.maxAgeDays).Format("2006-01-02")
	return fmt.Sprintf(
		"is:pr is:open -is:draft team-review-requested:%s created:>=%s",
		c.teamSlug, cutoff,
	)
}

func repoFromURL(repositoryURL string) (owner, repo string, err error) {
	_, after, found := strings.Cut(repositoryURL, "/repos/")
	if !found {
		return "", "", fmt.Errorf("repository_url %q has no /repos/ segment", repositoryURL)
	}
	parts := strings.Split(strings.Trim(after, "/"), "/")
	if len(parts) < 2 || parts[0] == "" || parts[1] == "" {
		return "", "", fmt.Errorf("repository_url %q does not name owner/repo", repositoryURL)
	}
	return parts[0], parts[1], nil
}

func (c *Client) ListTeamReviewRequests(ctx context.Context) ([]models.PullRequestSummary, error) {
	path := "/search/issues?q=" + url.QueryEscape(c.searchQuery())

	var results searchResponse
	if err := c.doWithRetry(ctx, "GET", path, nil, &results); err != nil {
		return nil, fmt.Errorf("searching for team review requests: %w", err)
	}

	summaries := make([]models.PullRequestSummary, 0, len(results.Items))
	for _, item := range results.Items {
		owner, repo, err := repoFromURL(item.RepositoryURL)
		if err != nil {
			return nil, err
		}

		var pull pullResponse
		detailPath := fmt.Sprintf("/repos/%s/%s/pulls/%d", owner, repo, item.Number)
		if err := c.doWithRetry(ctx, "GET", detailPath, nil, &pull); err != nil {
			return nil, fmt.Errorf("fetching %s/%s#%d: %w", owner, repo, item.Number, err)
		}

		summaries = append(summaries, models.PullRequestSummary{
			URL:          item.HTMLURL,
			RepoFullName: owner + "/" + repo,
			Number:       item.Number,
			Title:        item.Title,
			HeadSHA:      pull.Head.SHA,
			Body:         pull.Body,
			Branch:       pull.Head.Ref,
		})
	}
```

```go
			}
			files = append(files, models.FileChange{
				Path:      f.Filename,
				Patch:     f.Patch,
				Additions: f.Additions,
				Deletions: f.Deletions,
			})
		}

		if len(batch) < filesPerPage {
			break
		}
	}

	return models.PRContext{Summary: summary, Files: files}, nil
```

```go
package ghclient

import (
	"context"
	"fmt"
	"strings"

	"github.com/elinzer/go-pr-review-bot/internal/models"
)

const signature = "_—El + Claude PR review bot_"

type reviewComment struct {
	Path string `json:"path"`
	Line int    `json:"line"`
	Side string `json:"side"`
	Body string `json:"body"`
}

type createReviewRequest struct {
	CommitID string          `json:"commit_id"`
	Body     string          `json:"body"`
	Comments []reviewComment `json:"comments"`
}

type createReviewResponse struct {
	ID int64 `json:"id"`
}

func formatCommentBody(c models.Comment) string {
	var b strings.Builder

	prefix := "**[question]**"
	if c.Severity == models.SeverityBug {
		prefix = "**[bug]**"
	}

	fmt.Fprintf(&b, "%s %s\n\n_Evidence:_ `%s`", prefix, c.Body, c.Evidence.Citation)
	if c.Evidence.QuotedCode != "" {
		fmt.Fprintf(&b, "\n\n```\n%s\n```", c.Evidence.QuotedCode)
	}
	fmt.Fprintf(&b, "\n\n%s", signature)

	return b.String()
}

func (c *Client) CreatePendingReview(ctx context.Context, summary models.PullRequestSummary, review models.Review) (int64, error) {
	comments := make([]reviewComment, 0, len(review.Comments))
	for _, rc := range review.Comments {
		comments = append(comments, reviewComment{
			Path: rc.File,
			Line: rc.Line,
			Side: "RIGHT",
			Body: formatCommentBody(rc),
		})
	}

	body := review.Summary
	if len(review.Comments) == 0 {
		body = "LGTM! " + signature
	}

	payload := createReviewRequest{
		CommitID: summary.HeadSHA,
		Body:     body,
		Comments: comments,
	}

	path := fmt.Sprintf("/repos/%s/pulls/%d/reviews", summary.RepoFullName, summary.Number)

	var created createReviewResponse
	if err := c.do(ctx, "POST", path, payload, &created); err != nil {
		return 0, fmt.Errorf("creating pending review on %s#%d: %w",
			summary.RepoFullName, summary.Number, err)
	}

	return created.ID, nil
}
```

Note the deliberate omission: no `event` field in the payload. GitHub creates the review in `PENDING` state when `event` is absent — that is the entire mechanism keeping these reviews private until you submit them. Adding `"event": "COMMENT"` would post them publicly.

```go
var keyRe = regexp.MustCompile(`\b([A-Z]{2,}-\d+)\b`)

func ExtractKey(branch, body string) string {
	for _, source := range []string{branch, body} {
		if source == "" {
			continue
		}
		if m := keyRe.FindStringSubmatch(source); m != nil {
			return m[1]
		}
	}
	return ""
}

func adfToText(node any) string {
	switch v := node.(type) {
	case nil:
		return ""
	case string:
		return v
	case []any:
		var b strings.Builder
		for _, child := range v {
			b.WriteString(adfToText(child))
		}
		return b.String()
	case map[string]any:
		if v["type"] == "text" {
			text, _ := v["text"].(string)
			return text
		}
		return adfToText(v["content"])
	default:
		return ""
	}
}

	apiToken string
	http     *http.Client

	} `json:"fields"`

		return nil, nil

	req, err := http.NewRequestWithContext(ctx, "GET", url, nil)
	if err != nil {
		return nil, nil
	}
	req.SetBasicAuth(c.email, c.apiToken)
	req.Header.Set("Accept", "application/json")

	resp, err := c.http.Do(req)
	if err != nil {
		return nil, nil
	}
	defer resp.Body.Close()

		return nil, nil
	}

		return nil, nil
	}

		Title:              issue.Fields.Summary,
		Description:        adfToText(issue.Fields.Description),
```

```go
package notify

import (
	"bytes"
	"context"
	"encoding/json"
	"fmt"
	"log/slog"
	"net/http"
	"time"

	"github.com/elinzer/go-pr-review-bot/internal/models"
)

type Slack struct {
	webhookURL string
	dryRun     bool
	http       *http.Client
}

func NewSlack(webhookURL string, dryRun bool, timeout time.Duration) *Slack {
	return &Slack{
		webhookURL: webhookURL,
		dryRun:     dryRun,
		http:       &http.Client{Timeout: timeout},
	}
}

func formatMessage(summary models.PullRequestSummary, review models.Review) string {
	return fmt.Sprintf("Review ready on %s#%d: %s (%d comments) — %s",
		summary.RepoFullName, summary.Number, summary.Title, len(review.Comments), summary.URL)
}

func (s *Slack) NotifyReviewReady(ctx context.Context, summary models.PullRequestSummary, review models.Review) error {
	if s.webhookURL == "" {
		return nil
	}

	text := formatMessage(summary, review)

	if s.dryRun {
		slog.Info("dry run: would notify Slack", "text", text)
		return nil
	}

	payload, err := json.Marshal(map[string]string{"text": text})
	if err != nil {
		slog.Warn("slack notify failed", "url", summary.URL, "error", err)
		return nil
	}

	req, err := http.NewRequestWithContext(ctx, "POST", s.webhookURL, bytes.NewReader(payload))
	if err != nil {
		slog.Warn("slack notify failed", "url", summary.URL, "error", err)
		return nil
	}
	req.Header.Set("Content-Type", "application/json")

	resp, err := s.http.Do(req)
	if err != nil {
		slog.Warn("slack notify failed", "url", summary.URL, "error", err)
		return nil
	}
	defer resp.Body.Close()

	if resp.StatusCode < 200 || resp.StatusCode > 299 {
		slog.Warn("slack notify failed", "url", summary.URL, "status", resp.StatusCode)
	}

	return nil
}
```

### Task 13: Port `poller.py`

> **Go concept: `errors.Is` replaces `except SpecificError`.** `poller.py:47` catches `ValueError` to distinguish "the model returned garbage" from every other failure. Go has no exception types to catch — you compare against a sentinel with `errors.Is`, which unwraps through every `%w` in the chain. This is precisely why Task 6 defined `ErrUnparseable`.
>
> **Go concept: `context.WithTimeout` gives you a per-PR deadline for free.** Deriving a child context inside the loop means one wedged PR cannot stall the whole run — and every HTTP call underneath honors it without any extra plumbing. `defer cancel()` inside a loop body would pile up until the function returns, so this uses an inline function per iteration to scope it correctly. Forgetting `cancel()` leaks a timer.

```go
package poller

import (
	"context"
	"errors"
	"fmt"
	"log/slog"
	"time"

	"github.com/elinzer/go-pr-review-bot/internal/jira"
	"github.com/elinzer/go-pr-review-bot/internal/models"
	"github.com/elinzer/go-pr-review-bot/internal/reviewer"
	"github.com/elinzer/go-pr-review-bot/internal/state"
)

const maxParseFailures = 3

type GitHub interface {
	ListTeamReviewRequests(ctx context.Context) ([]models.PullRequestSummary, error)
	GetPRContext(ctx context.Context, summary models.PullRequestSummary) (models.PRContext, error)
	CreatePendingReview(ctx context.Context, summary models.PullRequestSummary, review models.Review) (int64, error)
}

type Jira interface {
	FetchTicket(ctx context.Context, key string) (*models.JiraContext, error)
}

type Reviewer interface {
	ReviewPR(ctx context.Context, pr models.PRContext, j *models.JiraContext) (models.Review, error)
}

type Notifier interface {
	NotifyReviewReady(ctx context.Context, summary models.PullRequestSummary, review models.Review) error
}

type Deps struct {
	GitHub       GitHub
	Jira         Jira
	Reviewer     Reviewer
	Notifier     Notifier
	DryRun       bool
	PerPRTimeout time.Duration
}

func RunOnce(ctx context.Context, deps Deps, st *state.State) error {
	summaries, err := deps.GitHub.ListTeamReviewRequests(ctx)
	if err != nil {
		return fmt.Errorf("listing review requests: %w", err)
	}

	toReview := st.Unreviewed(summaries)
	slog.Info("polled for review requests",
		"open_prs", len(summaries), "unreviewed", len(toReview))

	for _, summary := range toReview {
		processOne(ctx, deps, st, summary)
	}

	return nil
}

func processOne(ctx context.Context, deps Deps, st *state.State, summary models.PullRequestSummary) {
	ctx, cancel := context.WithTimeout(ctx, deps.PerPRTimeout)
	defer cancel()

	prCtx, err := deps.GitHub.GetPRContext(ctx, summary)
	if err != nil {
		slog.Error("fetching PR context; skipping", "url", summary.URL, "error", err)
		return
	}

	var jiraCtx *models.JiraContext
	if key := jira.ExtractKey(summary.Branch, summary.Body); key != "" {
		jiraCtx, err = deps.Jira.FetchTicket(ctx, key)
		if err != nil || jiraCtx == nil {
			slog.Info("jira ticket unavailable; proceeding without it", "key", key, "url", summary.URL)
		}
	}

	review, err := deps.Reviewer.ReviewPR(ctx, prCtx, jiraCtx)
	if err != nil {
		if errors.Is(err, reviewer.ErrUnparseable) {
			count, stErr := st.IncrementParseFailed(summary.URL)
			if stErr != nil {
				slog.Error("persisting parse failure", "url", summary.URL, "error", stErr)
			}
			slog.Warn("model response was unparseable", "url", summary.URL, "failure_count", count)
			if count >= maxParseFailures {
				if err := st.MarkSkippedManual(summary.URL); err != nil {
					slog.Error("marking PR skipped", "url", summary.URL, "error", err)
				}
				slog.Error("giving up on PR after repeated parse failures",
					"url", summary.URL, "failures", count)
			}
			return
		}
		slog.Error("reviewing PR; skipping", "url", summary.URL, "error", err)
		return
	}

	if deps.DryRun {
		slog.Info("dry run: would post review",
			"url", summary.URL, "summary", review.Summary, "comments", len(review.Comments))
		if err := st.MarkDryRunReviewed(summary.URL); err != nil {
			slog.Error("persisting dry-run marker", "url", summary.URL, "error", err)
		}
		notify(ctx, deps, summary, review)
		return
	}

	reviewID, err := deps.GitHub.CreatePendingReview(ctx, summary, review)
	if err != nil {
		slog.Error("creating pending review; skipping", "url", summary.URL, "error", err)
		return
	}
	if err := st.MarkReviewed(summary.URL, reviewID); err != nil {
		slog.Error("persisting review marker", "url", summary.URL, "error", err)
	}
	slog.Info("created pending review",
		"url", summary.URL, "review_id", reviewID, "comments", len(review.Comments))

	notify(ctx, deps, summary, review)
}

func notify(ctx context.Context, deps Deps, summary models.PullRequestSummary, review models.Review) {
```

### Task 14: Write `main.go`

> **Go concept: `log/slog` is stdlib structured logging.** It replaces Python's `logging` module with no dependency. `slog.SetDefault` installs a global handler so the packages that already call `slog.Info` start emitting through it. The key-value pairs after the message become structured fields.
>
> **Go concept: `os.Exit` skips `defer`.** The idiom is a `run() error` function containing all the real logic, with `main` doing nothing but calling it and exiting — so every `defer` in `run` still fires.

```go
package main

import (
	"context"
	"flag"
	"fmt"
	"log/slog"
	"os"
	"strings"
	"time"

	"github.com/elinzer/go-pr-review-bot/internal/anthropicclient"
	"github.com/elinzer/go-pr-review-bot/internal/config"
	"github.com/elinzer/go-pr-review-bot/internal/ghclient"
	"github.com/elinzer/go-pr-review-bot/internal/jira"
	"github.com/elinzer/go-pr-review-bot/internal/notify"
	"github.com/elinzer/go-pr-review-bot/internal/poller"
	"github.com/elinzer/go-pr-review-bot/internal/reviewer"
	"github.com/elinzer/go-pr-review-bot/internal/state"
)

const perPRTimeout = 10 * time.Minute

func main() {
	if err := run(); err != nil {
		slog.Error("fatal", "error", err)
		os.Exit(1)
	}
}

func run() error {
	flag.Parse()

	cfg, err := config.Load(true)
	if err != nil {
		return err
	}

	slog.SetDefault(slog.New(slog.NewTextHandler(os.Stderr, &slog.HandlerOptions{
		Level: parseLevel(cfg.LogLevel),
	})))

	st, err := state.Load(cfg.StatePath)
	if err != nil {
		return fmt.Errorf("loading state: %w", err)
	}

	deps := poller.Deps{
		GitHub: ghclient.New(cfg.GitHubPAT, cfg.GitHubTeamSlug, cfg.PRMaxAgeDays, cfg.HTTPTimeout),
		Jira:   jira.New(cfg.JiraBaseURL, cfg.JiraEmail, cfg.JiraAPIToken, cfg.HTTPTimeout),
		Reviewer: reviewer.Reviewer{
			Client: anthropicclient.New(cfg.AnthropicAPIKey, cfg.Model, cfg.AnthropicTimeout),
		},
		Notifier:     notify.NewSlack(cfg.SlackWebhookURL, cfg.DryRun, cfg.HTTPTimeout),
		DryRun:       cfg.DryRun,
		PerPRTimeout: perPRTimeout,
	}

	slog.Info("starting poll",
		"model", cfg.Model, "team", cfg.GitHubTeamSlug, "dry_run", cfg.DryRun)

	return poller.RunOnce(context.Background(), deps, st)
}

func parseLevel(name string) slog.Level {
	switch strings.ToUpper(strings.TrimSpace(name)) {
	case "DEBUG":
		return slog.LevelDebug
	case "WARN", "WARNING":
		return slog.LevelWarn
	case "ERROR":
		return slog.LevelError
	default:
		return slog.LevelInfo
	}
}
```

## What This Plan Deliberately Does Not Do

- **No concurrency.** PRs are reviewed sequentially, as in Python. Parallelizing needs a mutex on `State` (which rewrites the whole file per mutation) and rate-limit awareness. Do it as a follow-up once the port is verified.
- **No `-daemon` mode.** launchd's `StartInterval` handles scheduling, same as the Python version. `poller.RunOnce` is deliberately a single pass.
- **No retry on the Anthropic call.** The SDK retries 429s and 5xxs internally by default.
- **No change to the review prompt or the 5-comment cap.** Those are locked design decisions from the original spec.
